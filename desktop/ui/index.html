添加扩展
同一个包中的资源会按类型分别列入各页。新添加的资源默认停用。启用扩展会运行本机代码，文件和命令开关不限制扩展本身。安装时关闭安装脚本。

    
创建资源
名称使用小写字母、数字和连字符。保存为本机独立的 Pi 包，作用范围由上方选择。
