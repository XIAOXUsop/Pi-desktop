# Provider marks

The bundled `provider-logos.svg` contains a selected subset of the OpenCode provider sprite from `research/opencode-reference/packages/ui/src/components/provider-icons/sprite.svg`. Source: https://github.com/anomalyco/opencode/tree/dev/packages/ui/src/components/provider-icons . The accompanying MIT notice is preserved in `provider-logos.LICENSE` (Copyright (c) 2025 opencode).

The Command Code mark is its website's currently referenced mask icon: https://commandcode.ai/favicon/2024/safari-pinned-tab.svg (retrieved 2026-10-05). The XML declaration and document type were omitted, and its black fill inherits the interface color. This mark identifies the existing Command Code GOAT provider; it does not indicate endorsement.

Brand marks remain the property of their respective owners. Assets are bundled locally and make no requests to provider websites when the desktop is running. Custom providers use a generated initial badge, not a guessed model manufacturer logo.
